# Stillwater: feedback and issues

<img src="https://stillwater.rockystonelabs.com/assets/icon.png" width="96" align="right" alt="Stillwater's icon">

**Stillwater** is a free macOS menu bar app for Macs that run AI coding agents. It shows what each agent session
(Claude Code, Codex, Gemini CLI and others) is doing and what it costs your Mac, finds what a finished session left
running, and lets agents check the Mac before heavy test runs and model loads.

This repository is where you can **report a problem or ask for a feature**. Stillwater's source code isn't here.

- Website and download: https://stillwater.rockystonelabs.com
- Homebrew: `brew install --cask thewhey-brian/tap/stillwater`
- Requires macOS 15 or later, Apple silicon or Intel. Free, no account.

## Report a problem

[Open an issue](../../issues/new/choose) and include:

- Stillwater's version (Settings › About) and your macOS version
- what you did, what you expected, and what happened instead
- a screenshot of the dropdown if it helps (it shows only what's on your Mac; crop anything you'd rather not share)

Stillwater has no analytics and no crash reporter, so your report is the only way we hear about a problem.

## Privacy and security

Stillwater has no account, no analytics and no crash reporter, and never reads your agents' prompts or conversations.
To report a security issue privately, email support@rockystonelabs.com instead of opening an issue.
